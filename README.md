# אוסטריה למשפחה 2026 — אתר המסלול

אתר למסלול המלא לחופשה: מפת Google לכל יום, כפתורי ניווט ב-Waze, גלריית תמונות ליעדים, פותח אוטומטית ביום הנוכחי בזמן הטיול, וניתן להתקנה כאפליקציה בטלפון/מחשב (PWA).

## איך מעלים ל-GitHub Pages

1. בריפו הקיים שלך (`trip`), העלו את **כל הקבצים למעלה** תוך שמירה על מבנה התיקיות (כולל תיקיית `icons/`) — Add file → Upload files, גוררים הכל כולל את התיקייה, או `git add -A` + `git commit` + `git push`.
2. ב-**Settings → Pages** ודאו ש-Source הוא **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`.
3. אחרי דקה-שתיים האתר יתעדכן ב-`https://itairosenblum-hash.github.io/trip/`.

## התקנה כאפליקציה (PWA)

- **אנדרואיד (Chrome)**: בכניסה לאתר תופיע הצעה "התקן אפליקציה" / "הוסף למסך הבית" (או דרך תפריט שלוש הנקודות → "Install app").
- **iPhone (Safari)**: שיתוף (Share) → "הוסף למסך הבית" (Add to Home Screen).
- **מחשב (Chrome/Edge)**: סמל התקנה ⊕ בסרגל הכתובת, או תפריט → "Install".

לאחר ההתקנה האתר ייפתח כאפליקציה עצמאית (בלי סרגל דפדפן), עם האייקון שהכנתי (הר + שמש בצבעי האתר), ויעבוד גם אופליין הודות ל-Service Worker שכולל.

**חשוב לגבי האייקון**: אנדרואיד/Chrome ו-iOS "מצלמים" את האייקון ברגע ההתקנה בלבד — אם כבר התקנתם את האתר בעבר (למשל כשעדיין לא היה לו אייקון מותאם, או עם גרסה ישנה שלו), עדכון הקבצים באתר **לא** יעדכן אוטומטית את האייקון שכבר על המסך. צריך להסיר את הקיצור/האפליקציה הישנה מהמסך הראשי ולהתקין מחדש כדי לראות את האייקון העדכני.

**הצעה אוטומטית להתקנה**: האתר כבר לא מסתמך רק על כך שתמצאו את האפשרות בתפריט הדפדפן. באנדרואיד/Chrome/Edge יופיע באופן יזום פס אדום עם כפתור "התקן" (ברגע שהדפדפן מאותת שהאתר "כשיר להתקנה" — לפעמים לוקח כמה שניות/גלילה בביקור הראשון). ב-iPhone/iPad (Safari) אין לדפדפן אפשרות טכנית להציג כפתור התקנה אוטומטי, אז מוצגת הנחיה קצרה במקום ("הקישו שיתוף ⬆️ ואז הוסף למסך הבית"). מי שסוגר את הפס (✕) לא יראה אותו שוב באותו מכשיר/דפדפן.

## פתיחה אוטומטית ביום הנוכחי

בכל כניסה לאתר, אם התאריך של אותו רגע נמצא בטווח הטיול (24.9–3.10.2026), הוא **יפתח ישירות ביום הרלוונטי מהמסלול**. לפני הטיול או אחריו, הוא פותח כרגיל ב"מבט על — כל הטיול". זה מבוסס על התאריך והשעון של המכשיר של הצופה, כך שאין תלות בשרת.

## הערות טכניות

- **המפה**: מפה אינטראקטיבית (Leaflet + CARTO, ללא צורך במפתח API) שמציגה את כל המסלול (קו מקווקו עמום) ומדגישה עליה את קטע הנסיעה של היום שנבחר (קו אדום מלא + סימוני יעדים) — לא רק מרכוז, אלא המסלול בפועל. הקו עוקב אחרי הכביש האמיתי (ניתוב חינמי דרך OSRM, ללא מפתח), עם קו ישר כגיבוי אם השירות לא זמין, ולידו מוצגים מרחק וזמן נסיעה משוער. אפשר להחליף בין תצוגת רחוב לתצוגה טופוגרפית (כפתור 🛰️/🗺️ בפינת המפה) ולהרחיב את המפה למסך מלא (כפתור ⛶). לחיצה על סמן פותחת חלונית קטנה עם שם המקום וקישור ישיר ל-Waze.
- **Waze**: כל יעד נסיעה מקבל כפתור ניווט ישיר (`waze.com/ul?...`), וגם "פס עכשיו" (`nowBar`) שמופיע רק ביום הנוכחי בפועל של הטיול וקורא את לוח הזמנים כדי להציע אוטומטית את היעד הבא הרלוונטי לפי השעה.
- **מזג אוויר**: כרטיס בין המפה ללוח הזמנים, מציג תחזית יומית (Open-Meteo, ללא מפתח API) ליעד המרכזי של אותו יום. זמין רק כ-16 יום קדימה — לפני כן יוצג "התחזית עדיין לא זמינה". אם הבקשה נכשלת (בעיית רשת), מוצגת הודעה עדינה ושאר האתר ממשיך לפעול כרגיל.
- **כפתור WhatsApp**: כפתור צף בפינה השמאלית התחתונה, מקשר ישירות לקבוצת הוואטסאפ של הטיול.
- **ספירה לאחור**: תגית קטנה בכותרת — לפני הטיול מציגה כמה ימים נשארו לטיסה, ובמהלכו מציגה "יום X מתוך 10 בטיול".
- **התמונות**: גלריית התמונות מקושרת ישירות ל-Wikimedia Commons (רישיון פתוח). לחיצה על תמונה פותחת את עמוד המקור עם קרדיט מלא לצלם. אם תמונה ספציפית לא נטענת, היא מוסתרת אוטומטית ולא שוברת את העמוד.
- **ריענון אוטומטי (PWA)**: בכל פתיחה/חזרה לאפליקציה המותקנת, האתר בודק אוטומטית אם יש גרסה חדשה יותר בשרת (`registration.update()`), ואם כן — טוען אותה ומרענן את העמוד פעם אחת בעצמו, כך שתמיד רואים את הגרסה העדכנית בלי צורך לנקות מטמון ידנית. ה-Service Worker גם משתמש ב-`network-first` עם `cache:"no-store"`, כדי לעקוף גם את מטמון ה-HTTP הרגיל של הדפדפן ולא רק את המטמון הפנימי שלו.
- **שינויים עתידיים**: כל התוכן (לו״ז, תיאורי מקומות, קואורדינטות, תמונות, תאריכים) נמצא בתוך תגית `<script>` בקובץ `index.html`, במערכים `LOC`, `DAYS`, `IMAGES` ו-`DAY_DATES`. אפשר לערוך ישירות שם.
- אם משנים תוכן ב-`index.html`, שווה גם לעדכן את המספר בשורה הראשונה של `sw.js` (`CACHE = "austria-trip-v5"` וכו') — זה הטריגר שגורם למכשירים עם האפליקציה המותקנת לזהות שיש גרסה חדשה ולהוריד אותה. אם משנים את קובצי האייקונים עצמם, שווה גם להעלות את המספר `?v=5` שמופיע אחרי שמות קובצי האייקונים ב-`manifest.json` וב-`<head>` של `index.html`, כדי לוודא שהם לא יוגשו ממטמון ישן.
